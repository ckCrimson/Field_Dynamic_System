# Field Dynamic System (FDS)

A high-performance framework for Probabilistic State Machines defined by the tuple {S, V, F, G, $\Theta$}.

## Architecture
* **Core:** State Space and Field Algebra primitives.
* **Neighbor:** Topology and connectivity engines.
* **Generator:** JAX-optimized physics kernels.
* **Systems:** Orchestration and execution.
